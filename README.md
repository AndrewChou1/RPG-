# 幽闇地城 · Streamlit 小遊戲

這是一個以 **Python + Streamlit** 製作的文字風格 RPG 小遊戲示範，
可在瀏覽器中體驗探索、戰鬥、升級與章節推進。

## 遊戲特色

- 3 種職業可選：戰士、法師、盜賊
- 回合制戰鬥：普通攻擊、技能、道具、逃跑
- 地城探索事件：遭遇敵人、開寶箱、泉水回血
- 商店系統：購買消耗品與職業專屬裝備
- 角色成長：金幣、經驗值、升級、裝備加成
- 3 個章節與章節 Boss

## 環境需求

- Python 3.9+
- 套件：`streamlit`

安裝套件：

```bash
pip install streamlit
```

## 啟動方式

在專案目錄執行：

```bash
python -m streamlit run streamlit_demo.py
```

啟動後會自動開啟瀏覽器頁面（通常是 `http://localhost:8501`）。

## 基本玩法

1. 左側欄選擇職業並輸入角色名稱。
2. 點擊「開始新冒險」。
3. 在探索階段選擇：繼續探索、造訪商人、就地歇息、查看背包。
4. 進入戰鬥後使用攻擊、技能或道具擊敗敵人。
5. 逐層推進並挑戰每章 Boss，完成三個章節。
