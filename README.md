# 幽闇地城 · Streamlit 小遊戲

這是一個以 **Python + Streamlit** 製作的文字風格 RPG 小遊戲示範，
可在瀏覽器中體驗探索、戰鬥、升級、裝備養成與章節推進。

## 遊戲特色

- 3 種職業可選：戰士、法師、盜賊
- 回合制戰鬥：普通攻擊、技能、道具、逃跑
- 地城探索事件：遭遇敵人、開寶箱、泉水回血
- 商店系統：購買消耗品、職業專屬配件與戒指、武器強化
- 角色成長：金幣、經驗值、升級、裝備加成
- 3 個章節與章節 Boss，通關後可完成最終勝利

## 環境需求

- Python 3.9+
- 套件：`streamlit`

安裝套件：

```bash
pip install streamlit
```

## 啟動方式

在專案目錄執行：

```bash
python -m streamlit run streamlit_demo.py
```

啟動後會自動開啟瀏覽器頁面（通常是 `http://localhost:8501`）。

## 遊戲流程總覽

遊戲主要由「探索階段」與「戰鬥階段」輪流構成，核心循環如下：

1. 建立角色（選職業 + 命名）。
2. 在探索中前進，觸發隨機事件。
3. 遭遇敵人後進入回合制戰鬥。
4. 勝利後獲得金幣與經驗，持續成長。
5. 抵達章節底層後挑戰 Boss。
6. 擊敗 Boss 取得章節獎勵並進入下一章。
7. 完成第三章後達成通關。

## 職業說明

### 戰士

- 定位：高生存、高正面輸出
- 特性：血量厚、防禦高，容錯率高
- 技能：裂地斬（高倍率物理打擊）
- 適合：初次遊玩、偏好穩定推進

### 法師

- 定位：高爆發、依賴魔力
- 特性：MP 多、技能倍率高，但較脆
- 技能：烈焰爆破（超高倍率法術）
- 適合：喜歡快速解決戰鬥、管理 MP

### 盜賊

- 定位：靈活均衡、節奏快
- 特性：攻防中間值，戰鬥彈性高
- 技能：影襲連刺（高倍率且穩定命中）
- 適合：想兼顧輸出與操作感

## 玩法詳細說明

### 1. 開始冒險

1. 在左側欄選擇職業。
2. 輸入角色名稱。
3. 點擊「開始新冒險」。

建立後會進入第一章第 1 層，並顯示目前 HP、MP、攻防、金幣與裝備。

### 2. 探索階段

探索時可選擇以下操作：

- **繼續探索**：前進並觸發隨機事件。
- **造訪商人**：進入商店購買道具或裝備。
- **就地歇息（消耗金幣）**：回滿 HP / MP。
- **查看背包**：查看目前消耗品數量。

「繼續探索」會隨機出現三類事件：

- **遭遇敵人**：進入戰鬥。
- **發現寶箱**：獲得額外金幣。
- **遇見泉水**：恢復部分 HP。

### 3. 戰鬥階段（回合制）

每回合可執行一個行動：

- **攻擊**：穩定輸出，不消耗 MP。
- **技能**：高傷害，會消耗 MP。
- **道具**：使用藥水回復狀態。
- **逃跑**：有機率成功，失敗可能吃反擊。

戰鬥規則重點：

- 你行動後，若敵人仍存活，通常會反擊。
- 擊敗敵人可取得金幣與經驗值。
- 經驗值滿足條件會升級，提升 HP / MP 上限與攻防。
- 非 Boss 戰勝利後，可能獲得職業武器或直接自動裝備。

#### 攻擊與傷害計算公式

為了方便理解，攻擊可以拆成兩層：

1. 角色面板攻擊力（ATK）
2. 回合中實際造成的傷害（Damage）

角色 ATK 來源：

- 基礎攻擊（職業初始值）
- 升級加成（每升 1 級，攻擊 +2）
- 武器加成
- 武器強化加成（每級強化 +2，最高 +3）
- 帽子 / 配件 / 戒指加成（戒指可疊加）

可寫成：

$$
ATK = BaseATK + 2 \times (Level-1) + Weapon + Upgrade + Hat + Accessory + Rings
$$

玩家普通攻擊傷害：

$$
Damage = \max(1,\; ATK + \text{rand}(-2,3) - EnemyDEF)
$$

玩家技能傷害：

$$
Damage = \max\left(1,\; \text{round}(ATK \times SkillMult) + \text{rand}(-1,4) - \text{round}(EnemyDEF \times 0.6)\right)
$$

補充：

- $\text{rand}(a,b)$ 代表在區間 $[a,b]$ 內的整數隨機值。
- $\max(1,\cdot)$ 代表最少都會造成 1 點傷害，不會出現 0 傷害。
- 敵人的普通攻擊與技能也有類似公式，但技能對玩家防禦採用約 55% 的折抵（$\text{round}(DEF \times 0.55)$）。

### 4. 商店與裝備養成

商店中可進行三種強化方向：

- **消耗品補給**
	- 治療藥水：回復 HP
	- 魔力藥水：回復 MP
	- 萬能藥：HP / MP 全回
- **職業專屬裝備**
	- 配件：提供攻防或 MP 加成
	- 戒指：可累積多枚，疊加攻防收益
- **武器強化**
	- 武器可強化到固定上限
	- 每次強化提高攻擊力，費用逐級提升

提示：商店按鈕有短暫防連點機制，避免重複購買。

### 5. 章節推進與勝利條件

- 每章都有固定層數推進與章節 Boss。
- Boss 具備更高血量與能力，建議先準備補給與裝備。
- 擊敗章節 Boss 會自動獲得職業專屬獎勵裝備。
- 第一章、第二章完成後可進入下一章。
- 第三章 Boss 擊破即為正式通關。

## 新手建議

- 前期優先確保藥水存量，避免被連戰耗死。
- MP 型職業（法師）請留意技能與藥水節奏。
- 金幣不足時，先以探索拿資源再回商店補裝。
- 進 Boss 前盡量滿血、滿魔並完成至少一輪裝備提升。
